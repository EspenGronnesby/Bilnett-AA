# Endringslogg

Bilnett er en modifisert versjon av [AABrowser](https://github.com/kododake/AABrowser) av kododake (GPL-3.0).
Endringer under er gjort i Bilnett fra november 2026.

## Bilnett — 2026-11

### Lagt til
- Rave: fullskjerm «nå spilles» med cover, sangtekst og musikkvideo.
- Party-modus: lydspekter-ring rundt coveret i Trap Nation-/Bass Boosted-stil.
- Gjenkjenning av tung og distortert bass (zaag-/rawstyle-drops) med overdrevne spikes og lys på frekvenstoppene.
- Samspill med telefonens volum: rolig på lavt volum, ekstra strek, flere partikler og risting fra 70 %, ringen «tar av» ved 90–100 %.
- Strobe-blink ved maks volum og tunge kick.
- Ripple-bølger over hele skjermen, kun på sterk og distortert bass.
- Eget ikon for Rave.

### Endret
- Fartssperren i Rave («Parker bilen …») er fjernet. Rave leser ikke lenger GPS-hastighet.

### Fjernet
- Analytics-sporing til opprinnelig forfatters server (Umami). Bilnett sender ingen statistikk.

## Fra AABrowser (upstream, før Bilnett)
- Added new User Agent profiles (Firefox, Edge, Samsung Internet).
- Added a Custom User Agent profile with user-defined string.
